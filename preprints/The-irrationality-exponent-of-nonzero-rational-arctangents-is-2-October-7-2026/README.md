# The irrationality exponent of nonzero rational arctangents is 2

**Ryan Matthew Casper · October 7, 2026**

For every nonzero rational number r, arctan(r) is irrational and has irrationality
exponent 2. The argument extends OpenAI's weighted interpolation and determinant
method using Gaussian arithmetic, with a Lean formalization.
