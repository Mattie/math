# Explanations of the all-power degree bound

These accompany Ryan Matthew Casper's [*All-power weighted degree bounds for
monomial compactifications*](../paper.pdf), dated October 8, 2026. Choose the
background closest to yours; each version explains the same result.

| Version | Starting point |
|---|---|
| [ELIPHD](ELIPHD.md) | A PhD student in mathematics outside algebraic geometry and Diophantine approximation |
| [ELIMS](ELIMS.md) | A master's student comfortable with algebra and proof |
| [ELIBS](ELIBS.md) | A bachelor's student familiar with polynomials and basic proofs |
| [ELIHS](ELIHS.md) | A high-school student taking senior calculus |

The simpler versions begin with a number from the earlier logarithm paper. The
new note proves a degree bound used inside those arguments; it does not add a
new irrationality-exponent result.

For the exact theorem, use the [manuscript](../build/manuscript.md). The
[verification record](../VERIFY.md) describes the formal checks separately.
